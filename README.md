## How to run it

```bash
corepack pnpm install
corepack pnpm dev
```

Then build the rest yourself: auth, billing, database, AI agents,
background jobs, transactional email, OAuth apps for every provider, 12
theme packs, 12 locales of marketing copy, an admin panel, and a
storefront to sell it all — and keep it patched when the providers
change their APIs.

Easy.
